# Changelog

## 1.0.7 — 2026-08-28

- Replaced the old speaker artwork with the official Sonar logo.
- Fixed the oversized empty category block by changing the category icon canvas
  from 256×256 to the native 40×40 size expected by Touch Portal.
- Split the project overview into standalone English and Russian READMEs.

## 1.0.6 — 2026-08-26

- Reduced the category icon's opaque area to 48×48 px for a compact Touch
  Portal action-menu appearance.
- Added two transparent button images: headset microphone and studio microphone.
- Added public-release documentation and build instructions.

## 1.0.5 — 2026-08-26

- Added **Master - Set Microphone Input** and **Master - Next Microphone Input**.
- The Master microphone selector now writes both Streamer and Classic Sonar
  routes, so it stays consistent when the Sonar mode changes.
- Only physical microphone devices appear in the Master-microphone list.

## 1.0.4 — 2026-08-26

- Corrected the category icon sizing and true transparent PNG output.

## 1.0.3 — 2026-08-26

- Added device-list refresh, microphone cycling, duplicate-name handling, and
  compact transparent button images.

## 1.0.2 — 2026-08-15

- Added automatic reconnection after a Touch Portal or Sonar restart.

## 1.0.1 — 2026-08-15

- Added one-tap microphone mute.

## 1.0.0 — 2026-08-15

- First public version.
