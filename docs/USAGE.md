# Использование

## Первый запуск

1. Запусти SteelSeries GG и убедись, что Sonar включён.
2. В Touch Portal открой **Settings → Import plug-in…** и выбери файл
   `SteelSeriesSonar-vX.Y.Z.tpp`.
3. Полностью перезапусти Touch Portal: выйди из него через значок в трее и
   открой заново.
4. В редакторе кнопки найди категорию **SteelSeries Sonar**.

Администраторские права не нужны. Плагин работает только на Windows: Sonar —
локальная часть SteelSeries GG.

## Самые нужные действия

| Действие | Назначение |
| --- | --- |
| **Set Personal Mix (Monitoring) source** | Выбор устройства, которое слышишь ты. |
| **Set Streaming (audience) source** | Выбор устройства для зрителей. |
| **Master - Set Microphone Input** | Выбор физического микрофона в панели **МАСТЕР → Вход микрофона** Sonar. |
| **Master - Next Microphone Input** | Переход к следующему физическому микрофону одной кнопкой. |
| **Microphone Mute** | Мут микрофона: On, Off или Toggle. |

После подключения нового USB-микрофона нажми **Refresh audio devices**, затем
открой действие заново и выбери его в списке.

## Микрофон в панели Master

В режиме Streamer Sonar показывает нужный селектор слева: **МАСТЕР → Вход
микрофона**. Используй только действия с префиксом **Master**. Они намеренно
скрывают виртуальные устройства Sonar — в списке остаются физические
микрофоны и гарнитуры.

## Иконки для кнопок

Иконка категории плагина слева в списке действий и изображение твоей кнопки —
это разные вещи. Изображение кнопки назначается вручную в правой панели Touch
Portal, на вкладке изображения.

В папке `assets/` есть готовые PNG с прозрачным фоном:

- `headset_microphone.png` — гарнитура с микрофоном;
- `studio_microphone.png` — студийный микрофон.

Чтобы назначить картинку: выбери кнопку → вкладка изображения справа →
**Browse/Import** → выбери нужный PNG.
